贴源 · anchored
回执 provenance-linked 到触发它的 memo/命令,做成 chip 尾巴,不漂浮成独立卡。
活状态 · live
反映不快照:回读滴答显示 1/3、站点显示 live;文件存外部 id,状态靠 index,失败则优雅降级。
幂等 · idempotent
每晚重跑就地更新同一枚 chip,不刷屏出第 N 张回执;带 source-id,可撤销/重来。
安静 · quiet
effect 要被感到,不要被宣告。默认 ①,别把安静日记变成聒噪仪表盘。

一句话:回执不是内容,是收据——所以它贴着源卡当 chip、兜底进 Activity 时间线、只有要你决定时才 interrupt。这三态就是上一轮 surface/variant/resolver 的直接应用:chip variant 锚源卡 + 一个 Activity surface + 偶尔一个高优先 bid。
